# Local Ephemeral UI Workbench for Visual Editing and WebGL Rendering

Tasks that require visual human-in-the-loop interaction or browser Canvas/WebGL rendering—specifically image region-edit annotations (`ImageRegionEditDialog`), interactive local image tools (`ImageToolPanel`), freehand annotation (`ImageToolDialog`), video frame-sequence extraction and background removal (`FrameSequenceExtractorDialog`), and 3D model inspection with multi-angle sprite-sheet rendering (`Model3DViewport` + `Model3DFrameSequenceDialog`)—are served via an on-demand local HTTP server (`shared/asxlib/ui_server.py` built on Python's standard `http.server` bound to `127.0.0.1:0` with a one-time session token). The frontend components are ported from `image-flow` into `src/ui/` and pre-bundled at build time into static assets under `skills/asynx-<modality>/scripts/ui/`. When the user submits in the browser, the local Python process either submits the structured task (`source` + `annotation_preview` + `mask` + structured prompt) to the Asset Gateway or writes the exported artifacts (`atlas.png` + `manifest.json`) to disk, shuts down the ephemeral server, and emits a standard JSON payload back to the calling AI Agent.
